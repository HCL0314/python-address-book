# python-address-book

## 项目功能
- 添加联系人
- 删除联系人
- 修改联系人
- 查询联系人
- 显示全部联系人

## 如何运行
1. 确保电脑已安装 Python 3 环境。
2. 在终端或命令行中运行：`python address-book.py`
3. 根据屏幕数字菜单提示，输入对应编号即可操作。

## 已知问题
- 数据暂时保存在内存中，程序退出后数据会丢失。
- 对输入的数字编号没有做异常处理，输入字母会报错。

## 下一步准备加入什么功能
- 学习文件读写后，将数据保存到本地 JSON 文件，实现持久化。
- 增加更多联系人字段（如地址、邮箱）。

### 新增功能
- **数据持久化**：新增了将数据保存到本地 `address_book.json` 的功能，程序关闭后重新打开，数据依然存在，不再丢失。
- **增加字段**：在姓名和电话的基础上，新增了“地址”字段。

### 健壮性提升
- 增加了 `os.path.exists` 判断，防止因找不到文件导致崩溃。
- 增加了 `try-except` 异常处理，防止因 JSON 文件为空或格式损坏导致读取失败。
- 修复了删除和修改时，因未找到联系人导致的 `KeyError` 报错。

### 运行方式
1. 确保已安装 Python 3 环境。
2. 运行 `python address-book.py`。
3. 按菜单提示输入数字进行操作。首次运行会自动在同目录创建 `address_book.json` 文件。
